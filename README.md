# Multi-Page HTML Portfolio

This project is a semantic, HTML-only **multi-page portfolio website** built without any CSS or JavaScript.  
It demonstrates clean page structure, reusable navigation, SEO meta tags, and a contact form — all using pure HTML.

The goal of this project is to practice **HTML page architecture**, including headers, navigation bars, main content sections, footers, and multi-page linking.  
Styling will be added in a future project.
